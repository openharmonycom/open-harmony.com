# 1.0 OpenHarmony 英文版网站复刻

## 1.1 项目说明

`1.1.1` 这是一个参考 [OpenHarmony 官方网站](https://openharmony.cn/) 首页制作的静态英文网站，包含首页、栏目子页、兼容性结果页与案例详情页。

`1.1.2` 本项目不连接 OpenHarmony 的实时数据或后台服务。指标、设备测评记录及案例内容均为页面展示的参考内容。

## 1.2 本地查看

`1.2.1` 无需安装依赖或构建工具。从项目目录打开 index.html 即可浏览首页，页面之间通过相对路径互相链接。

## 1.3 页面与文件

`1.3.1` index.html：首页，包含项目横幅、社区数据、项目简介、开发入口、兼容性结果、解决方案与社区信息。

`1.3.2` develop.html：开发栏目。

`1.3.3` community.html：社区栏目。

`1.3.4` academy.html：学堂栏目。

`1.3.5` events.html：活动栏目。

`1.3.6` compatibility.html：兼容性栏目。

`1.3.7` devices.html：设备兼容性测评结果，支持按设备名称或厂商筛选。

`1.3.8` solutions.html：解决方案栏目。

`1.3.9` solution-case.html：智慧配电监控案例详情。

`1.3.10` about.html：项目介绍。

`1.3.11` subpages.css：栏目子页、设备结果页和案例页共用的导航与响应式样式。

`1.3.12` subpages.js：子页面移动端导航菜单的展开和收起逻辑。

`1.3.13` simulator.html：可交互的手机界面模拟器子页面。

`1.3.14` simulator.css：模拟器设备外观和响应式布局。

`1.3.15` simulator.js：模拟器应用切换、快捷设置、亮度和重置交互。

## 1.4 页面交互

`1.4.1` 首页社区指标在首次进入视口时递增播放一次；系统开启“减少动态效果”时直接显示最终值。

`1.4.2` 首页的 Download、Try it、Explore、Share 卡片链接到官方对应入口，并在新标签页打开。

`1.4.3` 顶部栏目链接会打开对应英文子页面。

`1.4.4` 设备结果页的搜索框可筛选设备和厂商。

`1.4.5` 子页面顶部导航在窄屏下会折叠为菜单。

`1.4.6` 模拟器可打开示例应用、切换快捷设置、调整亮度，并通过主页按钮或滑动手势返回。

`1.4.7` 模拟器仅为浏览器中的界面原型，不运行 HarmonyOS 系统或原生应用。

## 1.5 视觉与内容

`1.5.1` 设备插图与主视觉由 CSS 绘制，未直接使用官方图片素材。

`1.5.2` 官方入口链接会访问 OpenHarmony 网站或其文档站点。
